# Student Management System

A web application designed to facilitate the management of student and staff details, featuring separate dashboards for administrators and staff. Built using the MERN stack (MongoDB, Express.js, React.js, Node.js), this system streamlines the administrative processes in educational institutions.

## Table of Contents

- [Features](#features)
- [Technologies Used](#technologies-used)
- [Installation](#installation)
- [Usage](#usage)

## Features

- **Admin Dashboard**: 
  - Manage student and staff details.
  - Add, edit, and delete student and staff records.
  - View comprehensive statistics about students and staff.

- **Staff Dashboard**: 
  - Limited access to view student details.
  - Manage tasks and assignments.

- **Student Management**: 
  - View detailed profiles of students.
  - Track academic performance and attendance.



## Technologies Used

- **Frontend**: React.js
- **Backend**: Node.js, Express.js
- **Database**: MongoDB
- **Styling**: CSS, 

## Installation

To run the project locally, follow these steps:

1. Clone the repository:

   ```bash
   git clone https://github.com/yourusername/student-management-system.git
2. Navigate to the project directory:

  ```bash
  cd student-management-system
  ```

3.Install dependencies for both the backend and frontend:

  For the backend:
  ```bash
   cd server
   npm install
```
  For the frontend:
  ```bash
   cd frontend
   npm install
```
4.Start the backend server:

  ```bash
   cd backend
   npm start
```
5.Start the frontend server in a new terminal:
  ```bash
   cd frontend
   npm start
```
6.Open your browser and go to http://localhost:3000 to view the application.

### Usage
- Admins can log in to manage student and staff records.
- Staff can log in to view student details and manage their tasks.
- Use the provided dashboard features to navigate through the application.
